# GDGC Contributors Wall

A shared page where everyone who joined the GDGC GitHub workshop adds their name.
You will do it the way open source works: **fork, change, ask**.

## How to add yourself (5 steps, in your browser)

1. Click **Fork** (top right), then **Create fork**.
2. In your fork, open `CONTRIBUTORS.md` and click the **pencil icon**.
3. Add **one line** at the end of the list, using the format in the file.
4. Click **Commit changes...**, choose **Create a new branch for this commit**, and click **Propose changes**.
5. Click **Create pull request**.

A maintainer will review and merge it. Then find your name in `CONTRIBUTORS.md`.

## If your pull request says "This branch has conflicts"

That is normal. Many people edit the same file at the same time. Click **Resolve conflicts** and keep
**both** lines. See `CONTRIBUTORS.md` for what the markers look like.

## Rules

- Edit **only** `CONTRIBUTORS.md`, and only add your own line.
- Keep it kind and friendly. This repo is public.
- One pull request per person.
